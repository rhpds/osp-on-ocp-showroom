= Configure the operator-dependencies validated patterns section in the values-rhoso-gitops.yaml file

On the bastion, in your forked pattern repository:

[source,bash,role=execute]
----
cd /home/lab-user/rhoso-gitops
----

Edit `overrides/values-rhoso-gitops.yaml` so `operator-dependencies` includes the operator-dependencies component.

[source,bash,role=execute]
----
vim overrides/values-rhoso-gitops.yaml
----

Add the following block after the `applications` section:

[source,yaml]
----
applications:
  operator-dependencies:
    repoURL: https://github.com/openstack-k8s-operators/gitops
    path: example/dependencies
    targetRevision: v0.3.4
    kustomize:
      components:
        - "https://github.com/openstack-k8s-operators/gitops/components/argocd/hooks/postDelete/deploy-operators?ref=v0.3.4"
        - "https://github.com/openstack-k8s-operators/gitops/components/dependencies/provisioning-config?ref=v0.3.4"
        - "https://github.com/openstack-k8s-operators/gitops/components/argocd/annotations?ref=v0.3.4"
      patches:
        - target:
            kind: Job
            name: clean-observability
          patch: |-
            [
              {"op": "replace", "path": "/metadata/namespace", "value": "rhoso-gitops-standalone"},
              {"op": "replace", "path": "/spec/template/spec/serviceAccountName", "value": "standalone-gitops-argocd-application-controller"}
            ]
----

Commit the files created and push them to your GitHub repo:

[source,bash,role=execute]
----
git add overrides/values-rhoso-gitops.yaml
git commit -m "Configure operator-dependencies validated patterns section in the values-rhoso-gitops.yaml file"
git push origin
----

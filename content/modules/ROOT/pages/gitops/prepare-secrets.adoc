= Prepare RHOSO secrets with Validated Patterns

This chapter prepares every Secret used during the connected RHOSO installation
(`osp-secret`, `libvirt-secret`, `cinder-nfs-config`, dataplane SSH keys,
subscription manager, and Red Hat registry) by filling a local
`values-secret.yaml` file and loading it with the Validated Patterns framework.

Do **not** commit secret values to Git. Keep them only in the local secrets file
(and optionally encrypt it with Ansible Vault). For the full framework reference,
see
https://validatedpatterns.io/learn/secrets-management-in-the-validated-patterns-framework/[Secrets management in the Validated Patterns framework^].

== 1. Enable the secrets loader (`none` backend)

This lab uses the **none** secrets backend so
https://validatedpatterns.io/blog/2026-05-12-introducing-bootstrap-secrets/[bootstrap secrets^]
are injected directly into `openstack` (via `targetNamespaces`). That matches
the filled `values-secret.yaml` below.
On the bastion, in your forked pattern repository:

[source,bash,role=execute]
----
cd /home/lab-user/rhoso-gitops
----

Edit `values-global.yaml` so secret loading is enabled and the backend is
`none`:

[source,bash,role=execute]
----
cat > values-global.yaml <<'EOF'
---
global:
  pattern: rhoso-gitops
  secretLoader:
    disabled: false
  secretStore:
    backend: none
  options:
    useCSV: false
    syncPolicy: Automatic
    installPlanApproval: Automatic
main:
  clusterGroupName: standalone
  multiSourceConfig:
    enabled: true
    clusterGroupChartVersion: "0.9.*"
EOF
----

[NOTE]
Do not commit a filled `values-secret.yaml`. The pattern `.gitignore` already
excludes `values-secret.yaml`. You may commit the `values-global.yaml` change
above (it contains no secret material).

== 2. Prepare SSH key material for bootstrap secrets

The pattern expects key files under your home directory.
expects key files under your home directory. Create the Nova migration key pair
and copy the bastion dataplane keys to those paths:

[source,bash,role=execute,subs="attributes"]
----
cp "/home/lab-user/.ssh/{guid}key.pem" ~/dataplane-ansible-ssh-privatekey
cp "/home/lab-user/.ssh/{guid}key.pub" ~/dataplane-ansible-ssh-publickey

ssh-keygen -f ~/nova-migration-ssh-privatekey -t ecdsa-sha2-nistp521 -N ''
cp ~/nova-migration-ssh-privatekey.pub ~/nova-migration-ssh-publickey
----

== 3. Create your local `values-secret.yaml`

The pattern ships an empty template at `values-secret.yaml.template`. The loader
searches for a secrets file in this order and uses the first match:

. `~/.config/hybrid-cloud-patterns/values-secret-rhoso-gitops.yaml`
. `~/.config/validated-patterns/values-secret-rhoso-gitops.yaml`
. `~/values-secret-rhoso-gitops.yaml`
. `~/values-secret.yaml`
. `{{ pattern_dir }}/values-secret.yaml.template`

For this lab, copy the template next to the pattern and fill it in:

[source,bash,role=execute]
----
cd /home/lab-user/rhoso-gitops
cp values-secret.yaml.template ~/values-secret.yaml
----

Write the secrets file. Demo control-plane passwords match the connected lab
files (`openstack`). Replace the Red Hat credential placeholders with your own
values.

[IMPORTANT]
Add your username and password from the
https://www.redhat.com/wapps/ugc/protected/password.html[Red Hat Customer Portal^]
for `subscription-manager`, and a
https://access.redhat.com/articles/RegistryAuthentication#creating-registry-service-accounts-6[Registry Service Account^]
token for `redhat-registry`.

[NOTE]
This lab uses `global.secretStore.backend: none`, so OpenStack secrets are
injected directly as bootstrap secrets into `openstack`. The upstream template
also documents a `vault-approle-secret-id` entry for Vault+ESO; omit it here.

== Configure the secrets validated patterns section in the values-rhoso-gitops.yaml file

On the bastion, in your forked pattern repository:

[source,bash,role=execute]
----
cd /home/lab-user/rhoso-gitops
----

Edit `overrides/values-rhoso-gitops.yaml` so `secrets` is disabled since we are using the none backend and secrets are injected directly as bootstrap secrets into `openstack`.

[source,bash,role=execute]
----
vim overrides/values-rhoso-gitops.yaml
----

[source,yaml]
----
  openstack-secrets:
    enabled: false
----

Commit the files created and push them to your GitHub repo:

[source,bash,role=execute]
----
git add overrides/values-rhoso-gitops.yaml
git commit -m "Configure secrets validated patterns section in the values-rhoso-gitops.yaml file"
git push origin
----

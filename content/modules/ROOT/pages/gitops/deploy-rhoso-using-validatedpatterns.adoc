= Deploy RHOSO using Validated Patterns.

== Make sure you don't have any pending git commits in the repository

=== Lab repository

[source,bash,role=execute]
----
cd /home/lab-user/labrepo
git status
----
If you have any pending git commits, you need to commit them before continuing.
[source,bash,role=execute]
----
git add .
git commit -m "Final commit to update the lab repository"
----

Push the changes to the lab repository:
[source,bash,role=execute]
----
git push origin
----

== Access the OpenShift Gitops console to verify the deployment

Extract the password from the admin user Secret:

[source,bash,role=execute]
----
argoPass=$(oc get secret/openshift-gitops-cluster -n openshift-gitops -o jsonpath='{.data.admin\.password}' | base64 -d)
echo $argoPass
----

Get the Route for the OpenShift Gitops/OpenShift GitOps server:
[source,bash,role=execute]
----
argoURL=$(oc get route openshift-gitops-server -n openshift-gitops -o jsonpath='{.spec.host}{"\n"}')
echo $argoURL
----
